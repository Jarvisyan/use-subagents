# JARVIS 文档导航

本目录只保存适合公开、长期维护的项目文档。

| 文档 | 读者问题 |
|---|---|
| [`ARCHITECTURE.md`](ARCHITECTURE.md) | JARVIS 的角色、状态、协议、动态权重和安全边界是什么？ |
| [`PLAN.md`](PLAN.md) | 当前做到哪一步，下一阶段做什么，如何验收？ |

后续只在真实需求出现时增加文档：

- `QUICKSTART.md`：第一个可运行版本完成后加入；
- `CONFIGURATION.md`：出现稳定配置格式后加入；
- `examples/`：只放经过脱敏、可复现和许可检查的公开 Mission。

原始聊天、真实运行记录、模型完整输出和内部素材不属于公共文档。
